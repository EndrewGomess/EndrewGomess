## 🚀 Sobre Mim

Sou estagiário de **Engenharia de Dados na Programmers**, com foco em aprender e aplicar, na prática, os fundamentos de pipelines de dados: coleta, transformação, armazenamento e disponibilização de dados confiáveis para análise.

Estou no início da carreira e sigo uma rotina de estudos constante, combinando **certificações**, **projetos práticos** e o dia a dia de um ambiente real de dados. Gosto de entender o "porquê" por trás de cada etapa de um pipeline, escrever código limpo e documentar o que construo.

**O que estou buscando evoluir:**

- 🔹 Construção de pipelines ETL/ELT com Python e SQL
- 🔹 Processamento de dados com Spark e Databricks
- 🔹 Modelagem de dados e arquitetura Lakehouse (Medallion)
- 🔹 Boas práticas: versionamento com Git, organização de código e documentação
